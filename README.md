# OceanWatch — Ocean Pollution Awareness Using Technology

OceanWatch is a responsive, front-end educational website about **ocean pollution awareness using technology**. It connects environmental issues with computer science concepts such as AI-assisted monitoring, drones, IoT sensors, digital mapping, dashboards, and citizen science.

The project is designed for a B.Tech Computer Science and Engineering and Environmental Studies assignment. It presents the problem, selected evidence, a pollution timeline, possible technology-based responses, and project records in a dark, ocean-inspired interface.

## Features

- **Interactive landing page** introducing ocean pollution and the project.
- **Pollution pathway visualisation** showing how waste can travel from households, farms, and industries through drains and rivers to coastal areas and the ocean.
- **Evidence and data section** with animated number counters and visual comparisons.
- **Image showcase** that automatically rotates through images and supports manual navigation using the dots.
- **Ocean pollution timeline** describing key developments and growing awareness.
- **Technology overview** covering AI and computer vision, drones, satellite monitoring, IoT sensors, smart bins, digital mapping, dashboards, social media, and citizen science.
- **Animated interface** with reveal-on-scroll sections, a custom cursor effect, glowing details, and responsive layout styling.
- **Team and project-record sections** for presenting the project and related materials.

> **Important:** The site is an educational awareness website, not a live ocean-monitoring system. Its displayed figures and charts are presentation content, not real-time sensor feeds. Check the original references and dates before using any statistic in a formal report or presentation.

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

For a smoother development workflow, open the folder in Visual Studio Code and use the **Live Server** extension to launch the page locally. The extension is optional.

Some fonts and showcase images load from external websites, so an internet connection is needed for those resources. If an external image URL changes or becomes unavailable, replace it with a reliable source or a locally stored image.

## Sections on the Website

- **Evidence:** displays selected figures and visual comparisons.
- **Visuals:** presents imagery related to drones and coastal monitoring.
- **Timeline:** outlines developments in ocean-pollution awareness.
- **Technology:** introduces tools that may support detection, monitoring, education, and cleanup.

## Data and Responsible Use

Ocean pollution is a broad topic, and different measurements describe different things—for example, plastic production, plastic entering aquatic environments, marine litter observed at a location, and cleanup activity. These values should not be treated as interchangeable.

Before publishing or presenting the website:

1. Verify each statistic against its original report or scientific publication.
2. Include the source, publication year, geographic scope, and measurement units near the relevant figure.
3. Clearly label estimates, campaign totals, and illustrative visuals.
4. Do not describe the website as real-time monitoring unless it is connected to a functioning data source or sensor system.

The website's visuals explain how technology could help with awareness and monitoring; they do not prove that the listed technologies are currently deployed by this project.
